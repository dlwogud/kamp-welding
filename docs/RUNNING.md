# 제6회 K-인공지능 제조데이터 분석 경진대회 — ② 용접기 AI 데이터셋

공정 결합관계 학습 기반 로봇용접 이상탐지 — 라벨 해상도 제약 하의 검증 설계

---

## 1. 요약

제공 데이터의 불량 라벨이 용접점 단위가 아니라 **작업일 단위 집계**(8개 작업일, 총 39건)임을
확인하고, 예측 단위를 라벨 단위에 맞추어 과제를 세 층으로 재정의하였다.

| | 과제 A | 과제 B | 과제 C |
|---|---|---|---|
| 예측 단위 | 작업일 | 용접점 | 용접점 |
| 최종 모형 | 절편 전용 기준선 | **kNN 거리 (k=3), 물리 파생공간** | 가압력→전류, HistGB |
| 성능 | LOO-MAE 1.536 | **7유형 평균 ROC-AUC 0.971 / 최악 0.954** | **LODO R² 0.509** |

이상탐지는 **11모형×3특징공간×6개 합성 이상유형을 동일 조건에서 비교하고, 최종 kNN에는 A7 지속반복이상을 추가해 7유형 강건성을 점검했다.** 하이퍼파라미터는 중첩
교차검증으로 선택했다.

### 반드시 알고 볼 두 가지

**(1) 복제 구간 — 전체의 26.8%**

사전 기준 없이 공정변수 지문의 연속 일치 구간을 탐색한 결과, **800점 구간이 네 작업일에
동일하게 반복**되어 있다(3,200 / 11,939점). **2020-04-03 은 작업일 전체가 이 구간이다.**
`06_data_integrity.py` 가 확정하며, 모든 모델 학습·평가에서 제외된다.

**(2) 합성 이상 성능과 실제 불량의 연결은 다른 문제다**

0.971 은 **우리가 주입한 합성 이상**에 대한 성능이다. 실제 불량 39건과의 연결은
`16_defect_link.py` 에서 검정했고 **검출되지 않았다**(유의 0/5, 최소 순열 p 0.651).
다만 4개 지표의 부호가 모두 양으로 일관되었다. 이 결과를 숨기지 않고 보고서 2.8절에 싣는다.

### 현장 적용 권고

| 용도 | 방법 | 검증 |
|---|---|---|
| **일 단위 공정 이동 경보** | **가압력 일별 중앙값 2σ 관리도** | **실제 이동 3/3 탐지, 오경보 0/5** |
| 용접점 재검사 우선순위 | 컨포멀 p < 0.0038 | 합성 이상으로만 검증 |

정교한 용접점 탐지기를 순차 감시로 쓰면 실제 공정 이동을 0/3 탐지한다. 단순한 일 단위
관리도가 3/3 이다. **두 방법은 다른 문제를 푼다**(보고서 4.2절).

### 분석 과정에서 결론이 세 차례 뒤집혔다

| 회차 | 무엇이 틀렸나 | 정정 |
|---|---|---|
| 1 | 복제 구간을 이상의 기준으로 쓴 평가설계 | 순환 평가 확인, 재설계 |
| 2 | 이상유형 1종·특징공간 1종의 좁은 평가 | 최종 모형 교체 |
| 3 | 복제 구간을 '가압력 3bar 초과'로만 식별 | 291점 → **800점**, 4장 결론 번복 |

각 스크립트 docstring 에 그 단계에서 무엇이 기각되었는지를 기록하였다.

## 2. 실행 방법

### 2.1 환경 구성

```bash
python3.11 -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

Python 3.11 기준이며 GPU·인터넷 연결이 필요하지 않다. 제1~6장은 제공 데이터만 사용한다.
부록 A의 외부 검증(스크립트 22·23)만 외부 공개 데이터를 쓰며, 없으면 자동으로 건너뛴다(7절).

### 2.2 전체 실행

```bash
bash run_all.sh
```

전처리부터 학습·추론·결과생성까지 일괄 수행하며 `outputs/` 하위가 전부 재생성된다.
원본 데이터(`data/raw/`)는 수정하지 않는다. 전체 소요시간은 일반 노트북 기준 약 150분이며,
대부분은 `04_naive_check.py`(순열검정)에서 소요된다.

**마지막 단계가 종료 조건이다.** `25_manifest.py` 가 결과보고서 본문에서 인용 파일명을
직접 추출해(산출물 94개(검사기 자체 산출물 3개 제외)) 각 산출물이 **이번 실행에서 생성된 것인지** 검사한다.
과거 파일(`STALE`)이나 누락(`MISSING`)이 하나라도 있으면 **exit code 1** 로 끝난다.
결과는 `outputs/run_manifest.json` 에 SHA-256 과 함께 남는다.
외부 데이터가 없으면 보고서가 인용한 부록 A 산출물 7개가 `SKIPPED` 로 기록되며, 이는 정상이고
**본문 산출물은 전부 `FRESH`** 가 된다.

### 2.3 개별 실행

```bash
cd src
../.venv/bin/python 01_eda.py
```

스크립트 간 의존 관계는 아래 두 곳뿐이다.

- `03_daily_model.py` 와 `05_stable_window.py` 는 `02_risk_score.py` 가 생성하는
  `outputs/weld_risk_scores.csv` 를 읽는다.

따라서 개별 실행 시에는 `02_risk_score.py` 를 먼저 수행해야 한다.
`run_all.sh` 는 올바른 순서로 실행한다.

## 5. 재현성

- 난수를 사용하는 모든 지점에 시드 42 를 고정 (`np.random.default_rng(42)`, `random_state=42`).
- 몬테카를로 기반인 `09_power_analysis.py` 는 시뮬레이션 횟수를 상수로 명시 (`N_SIM = 4000`).
- 보고서의 모든 수치는 `outputs/tables/` 의 csv 에서 직접 확인 가능하며,
  보고서 각 표에 해당 파일명을 병기하였다.
- 제1~6장은 제공 데이터만 사용한다. 부록 A만 외부 공개 데이터를 쓰며, 본 패키지에 외부 데이터를 포함하지 않는다.
- 파이프라인 종료 시 산출물 진위 검사를 수행한다(`outputs/run_manifest.json`).

## 6. 분석상 주의사항

재현 시 아래 두 가지를 확인하면 본 분석의 핵심 판단 근거를 바로 볼 수 있다.

**(1) 라벨 해상도**

`result` 시트는 23행이며 작업일 × 불량유형의 집계 건수다. 용접점 단위 라벨이 아니다.
`01_eda.py` 의 표2(`t2_label_reality.csv`)가 이를 정리한다.

**(2) 가압력 고변동 구간**

가압력 3bar 초과 1,164점은 291개 레코드가 4개 작업일에 반복된 구조다
(정렬 후 내용해시 일치, 전류·전압 미세값까지 동일). `06_data_integrity.py` 가 해시 대조와
반증 대조로 확인한다. 본 분석은 해당 구간을 모델 학습·평가에서 제외하였다.
이 구간을 포함하면 평가가 순환하게 되며, 그 사례는 `07_model_comparison.py` 의
과제 B 1차 설계 결과에 남겨 두었다(보고서 2.2.1절).

## 7. 외부 데이터 (부록 A 전용)

부록 A의 방법론 검증은 KAMP 공개 데이터셋 ① 사출성형기, ③ 소성가공 예지보전을 사용한다.
**본 과제(② 용접기)의 분석이 아니며, 제출 패키지에는 포함하지 않는다.**

`22_external_press.py` 와 `23_external_mold.py` 는 아래 순서로 데이터를 찾고,
없으면 안내 후 건너뛴다. **건너뛰어도 제1~6장의 결과는 전부 재생성된다.**

1. 환경변수 `KAMP_PRESS_DIR` / `KAMP_MOLD_DIR`
2. `data/external/<데이터셋 폴더명>/`
3. `~/Downloads/<데이터셋 폴더명>/`

```bash
# 예시
export KAMP_PRESS_DIR="/path/to/3. 소성가공 예지보전 AI 데이터셋"
export KAMP_MOLD_DIR="/path/to/1. 사출성형기 AI 데이터셋"
bash run_all.sh
```

## 최종 결과 요약

### 데이터 진단
- 불량 라벨이 **작업일 단위 집계** (8일, 39건) → 용접점 단위 지도학습 불성립
- **복제 구간 800점 × 4일 = 전체의 26.8%**, 2020-04-03은 작업일 전체 (사전 기준 없이 탐색)
- 불량건수가 생산량에 비례하지 않음(ΔAIC 3.05), 유형 구성비 동질(p=0.885)

### 모델
| 과제 | 최종 모형 | 성능 |
|---|---|---|
| 용접점 이상탐지 | kNN 거리(k=3), 물리 파생공간 | **7유형 평균 0.971, 최악 0.954** |
| 정상운전 모델 | 가압력→전류 HistGB | **LODO R² 0.509** |
| 작업일 불량건수 | 절편 전용 기준선 | LOO-MAE 1.536 |

### 외부 검증 (부록 A)
- 소성가공 실제 라벨: **ROC-AUC 0.899**, 모형 순위 **1위/9**, 컨포멀 보장 충족
- 사출성형 LLP: 제품 라벨 **0.958** → 가방 집계 **0.627**

### 현장 활용
- **일별 가압력 중앙값 2σ 관리도 → 공정 이동 3/3 탐지, 오경보 0/5, 작업일 단위 정확 순열검정 p=0.0179**
  (평가 3일 = 03-25·03-31·03-27, 이 중 03-27은 예측대상일. 04-03은 복제 100%로 평가 제외 — 4.2.6절에 공개)
- 모델 기반 2단 공정윈도우 (내측 2.323~2.356 / 외측 2.260~2.383 bar, 외측이 내측 포함)
- 재검사 손익분기 농축배수, 복제 레코드 적재 점검 규칙

### 핵심 메시지
불량 예측은 **라벨이 존재하는 작업일 단위로 수행**했다 (03-27 → 4.88건 [1,10] 제출). 불가능한 것은 **용접점 단위**이며 **다섯 겹으로 입증**했다 (LLP 실측 / 시뮬레이션 / 외부 실제 라벨 / 39건 대조 / 전가라벨 이진분류 AUC 0.305). 다만 동등성 검정상 "관계 없음"도 주장 불가이므로 **"판정 불가"**로 보고한다.
→ 제언 1순위는 작업일 추가가 아니라 **용접점 단위 검사 기록**이다.

# 원본 데이터

이 디렉터리의 원본 데이터는 **본 저장소에 포함하지 않는다.**
KAMP(인공지능 제조 플랫폼)가 제공한 데이터이고 재배포 권한이 불확실하기 때문이다.

## 필요한 파일

| 파일 | 내용 |
|---|---|
| `Welding Data Set_01.xlsx` | 용접점 공정데이터(`Raw data`, 11,939행) · 불량 집계(`result`, 23행) · 변수 사전(`data set`) |
| `scaled_data.csv` | 스케일 변환본. **본 분석에서는 사용하지 않는다** (행 순서가 `Raw data`와 일치하지 않아 원자료에서 직접 전처리) |

## 받는 방법

1. https://www.kamp-ai.kr 로그인
2. 제조AI데이터셋 → **용접기 AI 데이터셋**
3. 내려받은 두 파일을 이 디렉터리에 그대로 둔다

```
data/raw/
├── Welding Data Set_01.xlsx
└── scaled_data.csv
```

## 데이터가 없어도 볼 수 있는 것

`outputs/` 에 분석 산출물이 전부 들어 있다 — 표 104종, 그림 40종,
용접점별 이상점수(11,939행), 테스트일 예측결과, 산출물 진위 매니페스트.
**데이터 없이 결과만 확인할 수 있다.**

재현하려면 위 두 파일이 필요하다. 없으면 `run_all.sh` 의 첫 스크립트에서 멈춘다.

## 부록 A(외부 검증)용 데이터

`22_external_press.py` 와 `23_external_mold.py` 는 KAMP의 다른 공개 데이터셋
(① 사출성형기, ③ 소성가공 예지보전)을 쓴다. 없으면 **자동으로 건너뛰며,
건너뛰어도 제1~6장 결과는 전부 재생성된다.**

찾는 순서: 환경변수 → `data/external/<폴더명>` → `~/Downloads/<폴더명>`
